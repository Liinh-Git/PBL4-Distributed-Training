--------------------

- Locator ownership: Backend/control plane resolve checkpoint_id; Runtime không query
  PostgreSQL và không nhận arbitrary filesystem path.
- Runtime derive checkpoint_root/source_attempt_id/deterministic-checkpoint-directory,
  reject invalid identity và mọi locator thoát checkpoint root.
- Integrity: verify metadata_sha256, model_sha256, Checkpoint V1, contract_hash,
  dataset_build_id, dataset_manifest_hash và parameter manifest/model compatibility.
- Restart: real-process E2E đã dừng Runtime, dựng Runtime mới, restore model_version 1,
  RecoveryCursor và hoàn tất ở model_version 6.
- Negative tests bao phủ unknown checkpoint, corrupt metadata/model, checksum mismatch,
  wrong contract/dataset, invalid identity và path escape.
