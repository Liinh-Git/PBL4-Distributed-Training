# Third-Party Skills Provenance

> Every external skill or code referenced from outside this repository
> must be recorded here. External skills are treated as dev supply-chain dependencies.

## Rules

- Do NOT track `main` branch — pin to exact commit SHA
- Do NOT auto-update without review
- Do NOT execute unreviewed external scripts

## Template

```
### [Skill Name]

| Field | Value |
|-------|-------|
| **Source repository** | https://github.com/... |
| **Exact commit SHA** | abc123... |
| **License** | MIT / Apache-2.0 / ... |
| **Imported / Reference-only** | Imported / Reference-only |
| **Local modifications** | None / Description |
| **Review date** | YYYY-MM-DD |
| **Reason for use** | Why this skill is needed |
```
